郭暾，宁夏中卫人，GitHub ID：FinnTew，Apache Seata 项目的 Committer，目前在百度搜索架构团队实习。在 Seata‑Go 中，他主要参与 AT 模式与 Saga 模式的建设，并在尝试推进 TCC 模式相关工作。


采访

### 1.请分享你是如何了解到 Seata/Seata-Go 项目的？

### 郭暾：我最初是通过去年一次“开源校园行”活动加入开源社区，当时接触的是 Dubbo Admin 项目，抱着想“先试一试”的心态。但由于某些原因未能推进。后来我了解到 Seata‑Go 在 Go 生态下，关于分布式事务（AT、Saga、TCC）有不少待做的任务，于是便转向参与这个项目。

### 2.在参与Seata/Seata-go开源项目的过程中，体验如何？

### 郭暾：在参与过程中，给我印象最深的便是社区氛围的友好与协作。作为新人，我得到了很多热情的帮助。虽然 Seata‑Go 的项目结构及事务模式（如 AT、Saga、TCC）都比较复杂，但社区讨论、代码审查、Issue 跟踪这些机制，让我能快速上手。

### 3.支撑你持续参与 Seata/Seata-go项目最大的动力是什么？在此过程中您觉得自己对项目最大的贡献是什么？

### 郭暾：起初，我参与是有一点功利性：想通过开源贡献增强求职竞争力。但当我提交第一个 PR 被合并，并且收到社区大佬详实的 code review 建议后，那种成就感让我真正留了下来。那一刻我意识到，其实我真正喜欢的是“参与、协作、学习、贡献”的过程。
至于我对项目的贡献，我认为有两方面：一是我在 code review 环节努力学习、避免提无意义建议、并提出合理优化；二是在理解 Seata‑Go 支持事务模式（如 TCC）流程时，我通过深入源码、调试调用链，帮助查漏补缺。虽然可能我的贡献看起来不是“重大功能上线”，但“少提错建议、多提出建设性意见”本身，对社区和项目质量也是有价值的。

### 4.参与  Seata/Seata-Go 开源过程中，遇到过哪些比较大的挑战呢？

### 郭暾：最大的挑战是在项目中做第一个 bug 修复（bug‑fix）的时候。当时对 Seata‑Go 的内部结构还不熟悉（包括 TM/RM/TC 三角色、事务模式交互、调用链深度等），我的调试方式也比较笨：经常查一个函数调用链、翻十几个文件，进度缓慢。但正是这种经历，让我真正理解了分布式事务框架中很多隐蔽的逻辑环节。最终当那个 bug 被定位并修复时，成就感远超预期。

### 5.成为Committer 后，对Seata/Seata-Go 的未来有什么期待吗？

### 郭暾：成为 Committer，对于我是一个肯定，也是一个新的起点。我希望 Seata‑Go 在 Go 生态中能获得更广泛的认知与应用 — 不仅在 AT 模式、Saga 模式上打好基础，也希望在 TCC 模式方面能够更成熟。我也希望能吸引更多志同道合的开发者加入社区，一起完善文档、示例、工业化支持。对个人而言，我希望能在功能支持、生产级稳定性、社区治理等方面做出更多贡献。

### 6.除了Seata/Seata-Go，还有没有参与其他的开源项目呢？

### 郭暾：在此前，我也参与过一些开源项目，尤其是“雨哥”的开源校园行项目，看到了一些项目从 C++ 迁移到 Rust 的过程。但目前，我已经将大部分精力集中在 Seata‑Go 上，希望通过深耕这个项目，在分布式事务这个细分领域做出更有意义的事情。

总的来说，郭暾在 Seata‑Go 中的成长轨迹，是开源生态里典型且具有启发意义的。他的热情、责任感与持续贡献，将有助于他在未来的开源道路上取得更大成就，也将为 Seata‑Go 项目及其用户群体带来更多价值。

## dubbogo概览


dubbogo项目已进入第九个年头。


项目初期使命是 “BridgingthegapbetweenJavaandGo”，目前已实现与ApacheDubbo版本全面对齐，并在云原生与智能化方向反哺Dubbo。在稳固Go语言生态RPC能力的基础上，dubbogo社区积极拥抱AI技术浪潮，探索在推理服务治理、模型分发与自动化运维方面的创新实践，致力于打造更适配AIGC和多模型场景的服务框架。


社区正在推进的dubbo-go-pixiu项目，实现了与SpringCloud、gRPC等生态的互联互通，不仅增强了协议适配能力，也为未来模型服务通信奠定了基础。同时，社区已着手调研AI时代下的数据流管控与推理链路优化，通过与主流模型服务平台和AI编排工具的集成，探索构建dubbogo在AI服务治理中的最佳路径。


dubbogo社区始终秉持开放协作理念，与阿里、腾讯等开源社区紧密合作。例如与RocketMQ社区共建基于MQEvent的通信能力，满足银行等行业对跨域通信的安全诉求；又如与腾讯Polaris社区协作，将Mesh网络中的注册、配置、路由能力融入dubbogo，为AI服务的动态调度提供坚实支撑。
