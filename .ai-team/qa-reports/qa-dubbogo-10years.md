### [CRITICAL] L101: "5 个在校生" 计数错误

原文：
```
这八个人，5 个在校生（方泽亚大二、史凤瑞大四、刘星岳大四、李雪涛研一），
1 个百度实习生（郭暾），1 个滴滴员工（张锋），1 个小公司工程师（吕晓锋）。
```

问题：括号里只列了 4 个在校生，但前面说 5 个。第 5 个应该是郭暾（实习生大概率也是在校生），但括号里没列他。

建议改为以下之一：
- `4 个在校生（方泽亚大二、史凤瑞大四、刘星岳大四、李雪涛研一），1 个百度实习生（郭暾）……`
- `5 个在校生（方泽亚大二、史凤瑞大四、刘星岳大四、李雪涛研一、郭暾实习中）……`

注意：凌烟阁原文中郭暾 bio 只写了"目前在百度搜索架构团队实习"，未提及学校。所以第一种写法更严谨。

## 文字终检

### [WARNING] L92: PR 链接格式

```
他的第一个 PR (apache/dubbo-go#2744) 只改了一行
```

半角括号 `(apache/dubbo-go#2744)` 在中文段落里略显突兀。全文其他地方都用全角括号。如果追求统一，可以改为：
```
他的第一个 PR（apache/dubbo-go#2744）只改了一行
```
但保留半角也不算错，因为 PR 引用本身就是英文格式。

### [INFO] 的/得/地 用法

抽查无问题。"地" 用在动词前（"一行一行代码地看"），"得" 用在补语前，用法正确。

无明显问题。英文单词和中文之间空格处理得当。
